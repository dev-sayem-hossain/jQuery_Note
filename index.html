jQuery শেখার সম্পূর্ণ গাইড

প্রতিটি প্রশ্নের উত্তর, প্রতিটি কোড লাইনের ব্যাখ্যা এবং শেষে একটি চালু মিনি প্রজেক্ট। (jQuery 3.7.1 ব্যবহার করা হয়েছে)

১. jQuery কী?

উত্তর: jQuery হলো একটি হালকা ও দ্রুত JavaScript লাইব্রেরি। এর স্লোগান: “Write less, do more” — অর্থাৎ কম কোড লিখে বেশি কাজ করা। এটি ২০০৬ সালে John Resig তৈরি করেন।

jQuery দিয়ে HTML এলিমেন্ট বাছাই, ইভেন্ট হ্যান্ডেল, অ্যানিমেশন ও AJAX এর কাজ খুব সহজে করা যায়। jQuery আলাদা ভাষা নয়; এটি JavaScript দিয়েই লেখা।

পেজে jQuery যোগ করার নিয়ম

২. JavaScript ও jQuery এর মধ্যে পার্থক্য কী?

উত্তর: JavaScript হলো ভাষা, jQuery হলো সেই ভাষায় লেখা একটি লাইব্রেরি (তৈরি করা ফাংশনের সংগ্রহ)। একই কাজ jQuery তে ছোট কোডে হয়।
বিষয়JavaScript (Vanilla)jQuery
ধরনপ্রোগ্রামিং ভাষাJavaScript লাইব্রেরি
কোডতুলনামূলক বড়ছোট ও সহজ
সেটআপকিছু লাগে নালাইব্রেরি ফাইল যোগ করতে হয়
গতিএকটু দ্রুতসামান্য ধীর (অতিরিক্ত ফাইল লোড হয়)
ব্রাউজার সমস্যানিজে সামলাতে হয়অনেকটা jQuery নিজে সামলায়

একই কাজ, দুই পদ্ধতিতে: “box” এলিমেন্ট লুকানো

৩. jQuery কীভাবে কাজ করে?

উত্তর: jQuery এর মূল ফাংশনের নাম jQuery, এর ছোট নাম $। আপনি $("selector") লিখলে সে পেজ থেকে এলিমেন্ট খুঁজে একটি jQuery অবজেক্টে ভরে দেয়। ওই অবজেক্টে আগে থেকে তৈরি মেথড (hide(), css() ইত্যাদি) থাকে, সেগুলো কল করলেই কাজ হয়।

ধাপগুলো: ১) পেজ লোড হয় → ২) $(document).ready() অপেক্ষা করে HTML তৈরি হওয়া পর্যন্ত → ৩) selector এলিমেন্ট খোঁজে → ৪) মেথড কাজ করে → ৫) মেথড একই অবজেক্ট ফেরত দেয়, তাই একটির পর একটি মেথড জোড়া দেওয়া যায় (Chaining)।

৪. jQuery সিনট্যাক্স (Syntax)

উত্তর: মূল গঠন: $(selector).action() — $ মানে jQuery শুরু, selector মানে কোন এলিমেন্ট, action() মানে তার উপর কী করা হবে।

৫. jQuery Variable কীভাবে তৈরি করে?

উত্তর: jQuery এর নিজস্ব কোনো variable নেই; JavaScript এর var, let, const ব্যবহার হয়। jQuery অবজেক্ট রাখলে নামের আগে $ দেওয়া একটি জনপ্রিয় নিয়ম, যাতে বোঝা যায় এটি jQuery অবজেক্ট।

লক্ষ্য করুন: একই এলিমেন্ট বারবার খোঁজার চেয়ে variable এ রেখে দিলে কোড দ্রুত ও পরিষ্কার হয়।

৬. jQuery Selectors (এলিমেন্ট সিলেক্ট করার নিয়ম)

উত্তর: Selector দিয়ে বলে দেওয়া হয় কোন HTML এলিমেন্টের উপর কাজ হবে। নিয়ম CSS selector এর মতোই।
Selectorঅর্থ
$("p")সব <p> ট্যাগ
$("#menu")id="menu" এলিমেন্ট
$(".item")class="item" সব এলিমেন্ট
$("ul li")<ul> এর ভেতরের সব <li>
$("ul > li")<ul> এর সরাসরি সন্তান <li>
$("li:first-child")প্রথম <li>
$("input[type='text']")attribute মিলিয়ে নির্বাচন
$("h1, p")একসাথে একাধিক selector
$(this)বর্তমানে যে এলিমেন্টে কাজ চলছে সেটি

৭. jQuery Events (ক্লিক, হোভার বা ইউজার অ্যাকশন হ্যান্ডেল করা)

উত্তর: ইউজার যা করে (ক্লিক, মাউস রাখা, কী চাপা, ফর্ম সাবমিট) তাকে Event বলে। jQuery তে .on("event", function) দিয়ে ইভেন্টে কাজ জুড়ে দেওয়া হয়।

জনপ্রিয় ইভেন্ট: click, dblclick, hover, mouseenter, mouseleave, keyup, keydown, change, submit, focus, blur।

৮. jQuery Effects ও Animation (লুকানো, দেখানো, ফেড ইন/আউট)

উত্তর: jQuery তে এলিমেন্ট দেখানো/লুকানো, ফেড ও স্লাইড করার তৈরি মেথড আছে: hide, show, toggle, fadeIn, fadeOut, slideUp, slideDown। নিজের মতো অ্যানিমেশনের জন্য animate()।

৯. jQuery AJAX (পেজ রিফ্রেশ ছাড়া ডেটা লোড করা)

উত্তর: AJAX দিয়ে সার্ভার থেকে ডেটা এনে পেজের একটি অংশ আপডেট করা যায়, পুরো পেজ রিলোড ছাড়া। jQuery তে এর জন্য $.ajax(), $.get(), $.post(), .load() আছে।

এই কোড ইন্টারনেট সংযোগে চালাতে হবে। কোড লোকাল ফাইলে না চালিয়ে ওয়েব সার্ভারে (যেমন Live Server) চালানো ভালো।

১০. jQuery Traversing (Parent, Child, Sibling খোঁজা)

    ১৪. AJAX Promise, POST ও একাধিক অনুরোধ

    উত্তর: $.ajax() একটি Promise-এর মতো অবজেক্ট ফেরত দেয়। তাই .done(), .fail(), .always() চেইন করা যায়, আর $.when() দিয়ে একাধিক অনুরোধ একসাথে সামলানো যায়।

    এই কোড ইন্টারনেট সংযোগে চালাতে হবে। jsonplaceholder একটি ডেমো API, তাই POST করলে আসল ডেটা সংরক্ষণ হয় না।
